<div class="df-section">

<h2>Architecture principles</h2>

<div class="df-grid">

<div class="df-card">
<h3>01 — Secure by design</h3>
<p>
Security controls belong in the architecture rather than being
added after deployment.
</p>
</div>

<div class="df-card">
<h3>02 — Automate everything repeatable</h3>
<p>
Infrastructure should be reproducible, version-controlled and
deployable through code.
</p>
</div>

<div class="df-card">
<h3>03 — Identity is the control plane</h3>
<p>
Modern enterprise security starts with identity, privilege,
device trust and continuous evaluation.
</p>
</div>

<div class="df-card">
<h3>04 — Architecture must ship</h3>
<p>
Good architecture has to survive implementation, operations,
budgets and real-world constraints.
</p>
</div>

<div class="df-card">
<h3>05 — AI with guardrails</h3>
<p>
AI adoption needs governed data, controlled identities,
security boundaries and observable workloads.
</p>
</div>

<div class="df-card">
<h3>06 — Evidence over slideware</h3>
<p>
Architecture decisions should be validated through PoCs,
testing, automation and measurable outcomes.
</p>
</div>

</div>
